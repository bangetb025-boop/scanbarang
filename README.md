# ScanBelanja - aplikasi nyata v1

- Scan barcode nyata menggunakan ZXing.
- Kamera nyata.
- Pengenalan gambar nyata menggunakan model pengenalan bentuk di browser.
- Nama, kategori, dan harga dapat dikoreksi sebelum disimpan.
- Pengeluaran dan database produk disimpan di localStorage.
- Barcode yang pernah dikoreksi akan dipelajari di database lokal perangkat.
- PWA installable.

Catatan: model pengenalan bentuk adalah classifier objek umum, bukan model pengenal merek/produk Indonesia. Untuk mengenali produk spesifik seperti merek minuman/mi secara akurat, tahap berikutnya adalah database produk khusus + model produk.
